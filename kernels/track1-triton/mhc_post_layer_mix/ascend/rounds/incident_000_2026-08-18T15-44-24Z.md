## Root cause

`baseline_adapter.py` line 7 reads:

```python
class ModelNew(nn.Module):
    def __init__(self):
        super(Model, self).__init__()
```

The `super(Model, self)` references `Model`, but the adapter renames the class to
`ModelNew` and the module no longer defines `Model`. The generator
`scripts/make_baseline_adapter.py` renames all `Name` nodes with id `Model`
(including the `super()` argument) to `ModelNew`; the on-disk
`baseline_adapter.py` was evidently not produced by that generator (or was
produced by a buggy pass), so the `super()` argument was left as `Model`.

The immutable `base.py` is correct: it defines `class Model(nn.Module)` with
`super(Model, self).__init__()`, which is self-consistent.
